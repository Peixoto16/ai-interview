# Contrato do harness (rascunho do dono do projeto)

O que o código garante, não importa o que a IA diga:

1. A IA **propõe**, o código **decide**.
2. A entrevista só acaba cedo se já tiver **6 perguntas e 2 follow-ups**.
3. Se a IA disser que uma pergunta é follow-up, o código **confere se é verdade**.
4. A nota final é calculada pelo **código**, porque **a IA pode errar**.

Cada item vira regras testáveis em `docs/spec.md`: 1 → VC-10; 2 → VC-01..04; 3 → VC-07; 4 → VC-09.
